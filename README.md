# Miller–Rabin Primality Test

This repository contains the report for a group project studying the mathematical theory behind the Miller–Rabin primality test.

The project develops the theory starting from Fermat's primality test and studies the bound on the proportion of Miller–Rabin nonwitnesses for composite integers.

## Topics

- Number theory
- Primality testing
- Miller–Rabin test
- Fermat's little theorem
- Chinese remainder theorem
- Probabilistic algorithms
